# 冷蔵庫コンパス — 冷蔵庫管理アプリ プロトタイプ

要件定義書（概要）に基づく動作プロトタイプ。純粋な HTML/CSS/JavaScript 製で、ビルド不要。

## 起動方法

任意の静的サーバーでこのフォルダを配信するだけです。

```
python -m http.server 8650 --directory fridge-app
# → http://localhost:8650 を開く
```

（`index.html` をブラウザで直接開いても動作します）

## 実装済み機能と要件の対応

| 要件 | 実装 | 備考 |
|---|---|---|
| 手入力登録 | ✅ | 食材名・数量・カテゴリ・賞味期限。カテゴリ選択で期限の目安を自動セット |
| レシート撮影登録（OCR） | ✅ 実装 | APIキー設定時は Claude Vision で実際に読取。未設定時はデモ動作。読取結果は登録前に編集可能 |
| バーコードスキャン登録 | ✅ 実装 | カメラ読取（対応端末）＋JANコード手入力。商品名は内蔵辞書→Open Food Facts の順で照会 |
| 在庫一覧（期限順ソート・強調表示） | ✅ | 期限切れ/3日以内を色分け。名前順・登録順ソートも可 |
| 賞味期限アラート（3日前通知） | ✅ モック | 起動時にバナー表示。設定画面で通知時刻を設定（実プッシュ通知は未実装） |
| AIレシピ提案（在庫優先） | ✅ 実装 | APIキー設定時は Claude が在庫と期限から3品を生成。未設定時は内蔵レシピDB＋期限優先スコアリング |
| 参照URLの提示 | ✅ | 各レシピにクックパッド/クラシルの検索URLを添付 |
| 不足食材の提示 | ✅ | 在庫にない材料を赤チップで明示 |
| 買い物リスト ワンタップ追加 | ✅ | 不足食材をボタン1つでリストへ。手動メモ追加も可 |
| 在庫データ自動連動 | ✅ | 「購入済み」チェックで在庫へ数量1・カテゴリ推定・デフォルト期限付きで自動加算 |
| ポモドーロ勉強タイマー | ✅ 実装 | 集中/休憩を自動で切り替えるインターバルタイマー。完了数と集中時間を日ごとに記録 |

## AI連携（任意・BYOK方式）

設定画面で **自分の Claude API キー**を登録すると、以下が実動作に切り替わります。未登録でもアプリは全機能そのまま使えます。

| 機能 | キー未設定 | キー設定時 |
|---|---|---|
| レシート撮影 | デモ（サンプル読取） | Claude Vision が実際に食材を抽出 |
| レシピ提案 | 内蔵レシピDB＋期限優先スコアリング | Claude が在庫と賞味期限から献立を生成 |
| バーコード | カメラ読取＋手入力（キー不要） | ＋バーコード写真からの読取 |

**キーの取り扱い**：キーはブラウザの localStorage にのみ保存され、送信先は Anthropic の API だけです。バックエンドは経由しません（`anthropic-dangerous-direct-browser-access` ヘッダによるブラウザ直接呼び出し）。利用量に応じて Anthropic から課金されます。共用端末では使用後に設定画面から削除してください。

## ポモドーロ勉強タイマー（勉強タブ）

集中と休憩を交互に繰り返すポモドーロ・テクニック用のインターバルタイマーです。冷蔵庫の機能とは独立して動きます。

- **フェーズ自動送り**: 集中 → 小休憩 →（設定回数ごとに）長い休憩、を自動で切り替え（オフにすれば手動開始）
- **時間はプリセット or 自由設定**: 25/5・50/10・15/3 のワンタップ切替、または集中1〜180分・休憩・長い休憩の間隔を個別指定
- **ズレない計測**: 残り時間は端末時計（`Date.now()`）から毎回計算するため、他タブを見ていても、画面を消しても、アプリを閉じて開き直してもズレません（実行中のタイマーは再読み込み後もそのまま継続）
- **終了の知らせ**: Web Audio で生成したチャイム（音声ファイル不要＝オフラインでも鳴る）＋バイブレーション、任意でシステム通知
- **画面が消えない**: 実行中は Screen Wake Lock で自動スリープを抑止（対応端末のみ）
- **学習の記録**: 今日の完了ポモドーロ数と集中時間、直近7日間のグラフ。記録は `fridge-compass-pomodoro-v1` に保存

## 残っている割り切り

- **プッシュ通知**: バナー表示のみ → Service Worker + Web Push が必要（iOSはホーム画面追加後のみ対応）
- **データ保存**: localStorage のみ。複数端末で同期する場合はバックエンド＋DBが必要
- **バーコード商品DB**: Open Food Facts は日本商品のカバー率が不完全。ヒットしない場合は手入力にフォールバック
- **タイマーの終了通知**: アプリを閉じている間は鳴りません（バックグラウンド通知には Web Push が必要）。開いたままにしておけば画面ロック中でも通知音は鳴ります
- **iOS のカメラ読取**: iOS Safari は `BarcodeDetector` 非対応のため、iPhone ではJANコード手入力か（キー設定時）写真読取を使用

## 更新をユーザーに届けるには

Service Worker が静的ファイルを cache-first でキャッシュするため、**JS/CSS を変更したら `sw.js` の `VERSION` を必ず上げてください**（例 `v3` → `v4`）。上げないと既存ユーザーには古いままの画面が表示され続けます。

## iPhone で使う（PWA）

Apple Developer Program（年$99）も Mac も不要で、iPhone にアプリとして入れられます。
HTTPS で公開して Safari の「ホーム画面に追加」を使う方式です。
→ 手順は **[DEPLOY_iOS.md](DEPLOY_iOS.md)** を参照。

- Service Worker によりオフラインでも全機能が動作
- ホーム画面から全画面起動（ノッチ/ホームバー対応済み）
- iOS で開くと「ホーム画面に追加」の案内バナーを表示

## ファイル構成

- `index.html` — 画面構造（在庫 / レシピ提案 / 買い物リスト / 勉強タイマー / 設定 の5タブ＋モーダル3種）
- `styles.css` — スタイル（スマホ想定 max-width 480px）
- `app.js` — 全ロジック。データは localStorage キー `fridge-compass-v1` に保存
- `timer.js` — ポモドーロ勉強タイマー。設定と記録は localStorage キー `fridge-compass-pomodoro-v1` に保存
- `pwa.js` — Service Worker 登録・iOS インストール案内
- `sw.js` — Service Worker（オフラインキャッシュ）
- `manifest.webmanifest` — PWA マニフェスト
- `icons/` — アプリアイコン（`make_icons.py` で生成）

設定画面の「データを初期化」でいつでもサンプルデータに戻せます。
